# `data/fire_records_US/`

| File(s) | What it is | Source |
|---|---|---|
| `fpa_fod_WA_ID_MT.*` | U.S. fire occurrences (Fire Program Analysis Fire-Occurrence Database, FPA-FOD) subset to Washington, Idaho, Montana. Point shapefile, NAD83 geographic (EPSG:4269). | USDA Forest Service (FPA-FOD) |

Used to characterise U.S. fire activity adjacent to the BC border for the cross-border comparison.
The full national FPA-FOD file is very large and is not redistributed here; only the WA/ID/MT subset
used in the study is included. See `../../DATA_SOURCES.md` for the source archive.
