# `data/climate/` — monthly climate tables (2000–2024)

Monthly climate and water-balance series for British Columbia, used by `climate_analysis.py`.

| File | Variable(s) | Source |
|---|---|---|
| `BC_TerraClimate_monthly_AET_2000_2024.csv` | Actual evapotranspiration | TerraClimate |
| `BC_TerraClimate_monthly_PDSI_2000_2024.csv` | Palmer Drought Severity Index | TerraClimate |
| `BC_TerraClimate_monthly_SOIL_2000_2024.csv` | Soil moisture | TerraClimate |
| `BC_ERA5Land_monthly_specific_humidity_2000_2024.csv` | Specific humidity | ERA5-Land |
| `merged_monthly_climate_2000_2024.csv` | All climate variables merged (long form) | derived |
| `BC_2000_2024_monthly_climate_wide.csv` | All climate variables (wide form) | derived |

See `../../DATA_SOURCES.md` for providers and access URLs.
