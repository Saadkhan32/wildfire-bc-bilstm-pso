# Metadata

- `iso19115_dataset.xml` - ISO 19115-2 geospatial metadata record (CRS EPSG:3005, extent, lineage, distribution, constraints).
- `training_points.csvw.json` - CSVW (JSON-LD) data dictionary for the modelling tables.
- `data_dictionary.csv` - human-readable column dictionary.
- `checksums_sha256.txt` - SHA-256 provenance hashes for every data file.

All spatial layers use NAD 1983 BC Albers (EPSG:3005). Tabular data are UTF-8 CSV.
